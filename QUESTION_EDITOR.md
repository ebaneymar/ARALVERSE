# Question order and bulk deletion — v1.5.92

Open **QUESTION EDITOR** and choose the term, subject and topic.

Imported / teacher-added questions play from the top of this list. Excel and
CSV imports keep the worksheet row order; another import or a manually added
question goes after the existing added questions. Use **↑ UP** or **↓ DOWN**
beside a question to move it one position. Changes save immediately and survive
restarting. Arrows change the full lesson order, including questions outside a
search. Selections stay checked when a question moves.

A new feeding activity, Classic Adventure battle or Tournament starts from the
first question. Questions continue in list order, then repeat from the first
after the full set. Retrying an incorrect feeding answer keeps that question.

- Tick **Select** beside imported or teacher-added questions, then choose **DELETE SELECTED**.
- **Select all** includes the complete list, including questions farther down the list.
- With a search entered, **Select all matching** selects every matching added question.
- **DELETE ALL** clears all imported / teacher-added questions in the selected lesson, including questions outside the search results. Its button and confirmation show the full count.

Confirm the deletion, then import the new Excel or CSV file. Built-in questions,
their saved edits and enabled/disabled settings, and other lessons are retained.
Changing the lesson or search clears the selection; closing the editor does too.

Deleting uses one question-bank save for the batch. Cancelling, a failed save,
or removing the last imported question pool during a running activity leaves
the question bank unchanged. Finish the activity or choose built-in questions
before clearing its last imported set. Deletions are saved across restarts.

## Optional clues in v1.5.93

Download the current Excel template to find **Pahiwatig** in column G, or add a column with that header to an existing Excel or CSV file. Use up to 600 characters for a clue. The import preview shows it before saving. To add or change a clue on a saved question, choose **EDIT** and fill in **PAHIWATIG (optional)**.

Enable **Pahiwatig muna** in Pakainin ang mga Alaga to use these clues on the first missed attempt. Existing files with the original required columns still import in worksheet order.
